# Folia Personal 0.7.22-personal.0.11

Windows x64 个人维护预发布，配套 HQPlayer 模组 0.2.6；不是上游官方发行版。本次没有 macOS / Linux 安装包。

## 更新内容

- 改善网络断流后的续播：条件允许时保持同一 HTTP 输入，用已验证的字节范围补传缺失数据，让播放器继续读取，不重新加载或重编码音频。
- 必须重新加载的恢复路径会核对实际进度推进和新输入读取，避免音频从头播放、界面却显示旧进度。不支持定位或无法确认时保持暂停并明确报错。
- HQPlayer 控制连接中断后，有界尝试新建控制连接，核对仍为同一音源再同步真实播放 / 暂停状态。不重启 HQPlayer、不重载歌曲，也不自动重发播放、跳转或暂停切换指令。
- 新增可选的已播放音频归档：HTTP 模组收到的完整原始音频可按平台、歌单和歌名保存；播放位置达到 80% 后复用已收字节补齐，完整性校验通过后可优先使用本地文件。默认关闭，需自行选择目录并开启。
- 遥控小窗口显示缓冲状态和实际音频下载速度；修复后端切换、切歌与恢复期间的部分状态衔接问题。
- 普通媒体缓存和长期归档合并为「音频缓存与归档」栏目。原有开关、目录及文件保留；清理缓存不会删除归档。

## 主程序和模组分别更新

1. 主程序：下载 `Folia-Setup-0.7.22-personal.0.11.exe` 安装，或在旧个人版中使用「检查更新 → 立即更新 → 重启安装」。
2. HQPlayer 模组：另行下载 `hqplayer-0.2.6.zip`，在模组页导入更新并重新确认信任。仅更新主程序不会覆盖已有模组。

与上次公开的个人版 0.7.22-personal.0.4 相比，此版汇总了期间的归档、弱网恢复、原生定位确认和控制重连改进。之前的版本化安装包保留，不再替换同版本内容。

## 验证与限制

相关回归、类型检查及模组静态检查通过。实际模组 ZIP 在本地 TCP 模拟器中验证了连续切歌、播放 / 暂停 / 定位、只读控制重连和清理；安装包比对了 181 个主进程 / 共享源文件，并核对了 443 个运行依赖。用户反馈本机使用正常；这些结果不代表全部平台音源、容器、设备或长时间播放均已验证。

安全续传需要可核对的资源版本、总长度与正确的 Range 响应；上游忽略范围、版本改变、签名失效或不支持定位时，不拼接不明内容，不保证能够恢复。归档只适用于当前支持的完整原始输入，不保存试听、DRM 或无法确认完整性的数据，也不是 HQPlayer 升频后的输出。详见[恢复边界](../playback-backends.md)与[归档说明](../audio-archive.md)。
